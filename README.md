# BMW M5 E39

Односторінковий сайт про третє покоління BMW M5 — першу M5 з восьмициліндровим
двигуном. Три сторінки: головна, модель та журнал. Тільки фронтенд.

## Запуск

```bash
npm install
npm run dev
```

Збірка для продакшену:

```bash
npm run build
```

## Стек

- React 18 + Vite
- React Router (HashRouter — працює на будь-якому статичному хостингу)
- Montserrat, CSS без фреймворків

## Структура

| Шлях | Що всередині |
| --- | --- |
| `src/data/content.js` | Увесь текст, цифри й підписи до фотографій |
| `src/pages/` | Головна, Модель, Журнал |
| `src/components/` | Прелоадер, навігація, курсор, індикатор прокрутки, лічильник цифр |
| `src/hooks/` | Завантаження зображень із реальним прогресом, паралакс |
| `public/photos/` | Оптимізовані зображення |

Текст і характеристики зібрані в одному файлі — щоб правити вміст,
верстку чіпати не треба.
